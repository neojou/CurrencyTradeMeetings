# Currency Trade Meetings

![Forex Chart](./images/forex_meeting.png)
> 模擬專業外匯交易團隊的 USD/JPY 每日晨會記錄

網誌：[AI 日圓外匯交易團隊會議記錄](https://neojou.blogspot.com/2026/02/ai-2026216.html)

## 倉庫介紹

本倉庫用來存放 **USD/JPY 貨幣對每日晨會** 的完整過程與紀要。

晨會由 AI 驅動，模擬一個完整的交易團隊，成員包括：
- **Rate Reporter**：即時匯率與走勢報告
- **News Analyst**：最新外匯新聞與影響分析
- **Technical Analyst**：技術指標與圖表解讀
- **USD Bull Trader**：美元多頭積極觀點
- **JPY Bull Trader**：日圓多頭保守防禦觀點
- **Team Lead**：最終決策與方向判斷
- **Minute Taker**：會議紀要總結

每場晨會都包含**數據報告 → 觀點辯論 → 最終決策**的完整流程，模擬真實交易室氛圍。

## 為什麼用 GitHub？

- GitHub 能直接渲染 `.md`（Markdown）檔案，點擊即可閱讀格式化的會議內容
- 以日期命名檔案，方便按時間順序回顧歷史會議
- 版本控制自動保留每次會議的完整紀錄

## 檔案結構
```text
CurrencyTradeMeetings/
├── README.md                  # 本說明文件
├── 2026-02-15.md              # 範例：2026 年 2 月 15 日晨會紀錄
├── 2026-02-16.md              # 每日會議獨立檔案
└── ...                        # 未來每日新增
```

每份會議檔案包含：
1. 各角色完整發言與辯論
2. 關鍵數據、技術指標、新聞事件
3. Team Lead 最終決策（方向、目標價位、止損）
4. Minute Taker 結構化會議紀要

## 如何使用

1. 點擊左側檔案列表，選擇日期檔案
2. GitHub 會自動渲染 Markdown，閱讀體驗極佳
3. 可使用 GitHub 搜尋功能快速查找關鍵詞（如「152.50」、「Carry Unwind」）
