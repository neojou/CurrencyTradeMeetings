## 倉庫介紹

本倉庫用來存放以 **日圓匯率（USD/JPY）為核心** 的 ETF 投資組合操盤每日晨會的完整過程與紀要，
涵蓋 **00706L（期元大S&P日圓正2）** 與 **00707R（期元大S&P日圓反1）**，
涵蓋 USD/JPY 匯率市場分析、00706L 技術面與策略評估、增減倉決策記錄。

晨會由 AI 驅動，模擬一個完整的交易團隊，成員包括：

**【日圓市場分析組】**
- **Rate Reporter**：即時 USD/JPY 匯率與走勢報告
- **News Analyst**：最新外匯新聞與影響分析
- **Technical Analyst**：USD/JPY 技術指標與圖表解讀

**【ETF 操盤組】**
- **ETF Market Reporter**：00706L / 00707R 當前交易市場狀況價位報告分析
- **ETF Technical Analyst**：00706L / 00707R 技術線型分析
- **ETF Strategy Analyst**：00706L / 00707R 複盤策略研究分析（進場濾網、風險報酬比）


**【交易觀點組】**
- **USD Bull Trader**：美元多頭積極觀點，建議減倉 00706L
- **JPY Bull Trader**：日圓多頭保守防禦觀點，建議增倉 00706L

**【決策與紀錄組】**
- **Team Lead**：整合所有分析，最終決策增倉/減倉方向、數量、停利停損
- **Minute Taker**：會議紀要總結

**【決策者】**
- **Owner**：（您本人）提供持倉資訊、參與討論、唯一有權結束會議


每場晨會都包含**數據報告 → 觀點辯論 → 最終決策**的完整流程，模擬真實交易室氛圍。

## 為什麼用 GitHub？

- GitHub 能直接渲染 `.md`（Markdown）檔案，點擊即可閱讀格式化的會議內容
- 以日期命名檔案，方便按時間順序回顧歷史會議
- 版本控制自動保留每次會議的完整紀錄

## 檔案結構
```text
CurrencyTradeMeetings/
├── README.md                  # 本說明文件
├── 2026-02-15.md              # 範例：2026 年 2 月 15 日晨會紀錄
├── 2026-02-16.md              # 每日會議獨立檔案
└── ...                        # 未來每日新增
```

每份會議檔案包含：
1. 各角色完整發言與辯論
2. 關鍵數據、技術指標、新聞事件
3. Team Lead 最終決策（方向、目標價位、止損）
4. Minute Taker 結構化會議紀要

## 如何使用

1. 點擊左側檔案列表，選擇日期檔案
2. GitHub 會自動渲染 Markdown，閱讀體驗極佳
3. 可使用 GitHub 搜尋功能快速查找關鍵詞（如「152.50」、「Carry Unwind」）
