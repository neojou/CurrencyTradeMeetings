# DCI 雙元投資（Dual Currency Investment）簡介與交易規則

## 什麼是 DCI？

DCI（Dual Currency Investment，雙元投資）是一種結合**定期存款**與**外匯選擇權**的結構性金融商品。
投資人以某一貨幣存入本金，並授權銀行在到期時依約定匯率（履約價格）決定以**原幣**或**另一幣別**返還本金與利息。

由於投資人承擔了匯率轉換風險，因此 DCI 提供的利率**遠高於**一般定期存款，但**本金並不保證**以原幣返還。

> **適合族群**：對外匯有一定看法、願意承擔匯率波動風險、追求較高收益的投資人。

---

## 核心概念

| 名詞 | 說明 |
|------|------|
| **投資幣別** | 投入本金的貨幣 |
| **連結幣別** | 可能被轉換的目標貨幣 |
| **連結標的** | 兩種貨幣的即期匯率（如 USD/JPY） |
| **履約價格 K1** | 主要比較匯率基準，決定是否轉換幣別 |
| **履約價格 K2** | 次要比較匯率基準（通常為 K1 的某百分比），決定是否適用本金折損條款 |
| **比價日** | 銀行以當日收盤匯率與履約價格比較的日期 |
| **預定到期日** | 實際資金返還日，通常在比價日後 1～2 個營業日 |
| **收益率（年率）** | 投資期間適用的年化利率（稅前） |

---

## 利息計算公式

$$
利息（稅前）= 本金 \times 年利率 \times \frac{投資天數}{全年天數}
$$

- 全年天數通常以 **360 天**計算（依各銀行規定為準）
- 利息幣別與本金相同

**範例：**
```

本金 = 2,000,000 JPY
年利率 = 9.87%
投資天數 = 9 天
全年天數 = 360 天

利息 = 2,000,000 × 9.87% × (9/360) = 4,935 JPY（稅前）

```

---

## 履約價格設定

DCI 通常設有**兩個履約價格**，分別對應不同的到期情境：

- **K1**：主要履約價格，由銀行與投資人議定，通常接近成交當下的即期匯率
- **K2**：保護性履約價格，通常為 K1 乘以某一比例（如 70%），觸發後將導致本金部分損失

$$
K2 = K1 \times 保護比例（例如\ 70\%）
$$

---

## 到期情境規則

比價日當天，銀行以**當日收盤匯率**（比價價格）與履約價格進行比較，依下列三種情境返還資金：

### 情境一：比價價格 ≥ K1

> 匯率未跌破履約價，幣別**不轉換**

- 以**原始投資幣別**返還本金與利息
- 投資人取回：**本金 + 利息**

```

取回金額 = 本金 + 利息

```

---

### 情境二：K2 ≤ 比價價格 ＜ K1

> 匯率跌破 K1，但未跌破 K2，幣別**依 K1 轉換**

- 本金與利息合計，依**履約價格 K1** 兌換成**連結幣別**返還
- 投資人取回：**(本金 + 利息) ÷ K1**（以連結幣別計）

```

取回金額（連結幣別）= (本金 + 利息) ÷ K1

```

---

### 情境三：比價價格 ＜ K2

> 匯率跌破 K2，觸發**本金折損**條款

- 僅返還本金的一定比例（對應 K2/K1 的比率，如 70%），利息照算，以**原始投資幣別**返還
- 投資人取回：**本金 × 保護比例 + 利息**

```

取回金額 = 本金 × 保護比例（如 70%）+ 利息

```

---

## 到期情境速查表

| 情境 | 比價條件 | 幣別轉換 | 取回金額計算 |
|:----:|----------|:--------:|--------------|
| 情境一 | 比價價格 ≥ K1 | 否 | 本金 + 利息（原幣） |
| 情境二 | K2 ≤ 比價價格 ＜ K1 | 是（依 K1） | (本金 + 利息) ÷ K1（連結幣） |
| 情境三 | 比價價格 ＜ K2 | 否 | 本金 × 保護比例 + 利息（原幣） |

---

## 主要風險提示

1. **匯率風險**：比價日匯率若跌破 K1，本金將被強制轉換為連結幣別，若持有連結幣別對投資人不利，可能產生實質損失。
2. **本金損失風險**：若匯率跌破 K2，僅能取回部分本金，損失幅度視保護比例而定。
3. **流動性風險**：DCI 屬於**不可提前解約**的商品，資金於到期日前無法動用。
4. **利息稅負**：所有利息均為**稅前**金額，實際取回利息需依當地稅法扣繳所得稅。
5. **非存款保障商品**：DCI 不屬於一般存款，不在存款保險保障範圍內。

---

## 交易流程摘要

1. **議定條件**：與銀行確認幣別組合、本金、履約價格（K1、K2）、收益率、投資天數
2. **資金入帳**：投資人將本金存入指定帳戶，交易生效
3. **持有期間**：資金鎖定，不可提前贖回
4. **比價日**：銀行於比價日收盤後，以即期匯率與 K1、K2 比較，判定返還情境
5. **到期日返還**：依比價結果，於預定到期日將本金與利息（或轉換後金額）返還投資人
