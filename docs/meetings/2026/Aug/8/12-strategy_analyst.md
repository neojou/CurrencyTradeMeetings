### 4.1 問答存檔：為何「中線略偏日圓」仍建議全賣 00706L？

> **Owner 疑問：** 若之後日圓升值可能性仍較高，為何全賣？是否因也可能繼續跌？  
> 單就 00706L 續抱，Kelly 報酬是多少？  
> **本節為 Strategy Analyst 完整分析紀錄（對齊 strategy.md §3.2–§3.5）。**

#### （1）一句話結論

1. **是的，也包含「還可能繼續跌／USD 再走強」**，但更關鍵是（2）（3）。  
2. 覆盤「略偏日圓」= **1–3 個月溫和中樞下移**；00706L Kelly = **約 5–9 天內「夠大的」日圓升** → **不是同一件事**。  
3. 本場 P 下續抱 **Kelly \(f^{*}\) 為負** → **最優倉位 = 0（全出）**。

#### （2）兩種「日圓升」不可混用

| | 覆盤「中線略偏日圓」 | 00706L Kelly 的「日圓升」 |
| :-- | :-- | :-- |
| 時間 | 一週～三個月中樞 | **約 5–9 個交易日**一輪（§3.5） |
| 幅度 | 例：157.8 → **156.0**（約 **−1.1%** 匯價） | 約 **1σ ≈ USD/JPY 跌 3.39%** 才接近模型「贏」檔（§3.2） |
| 對 00706L | 方向對也不一定賺（日結耗損） | 贏約 **+6.44%**，輸約 **−7.12%**（不對稱） |
| 門檻 | 敘事／預測 | **P ≥ 52.5%** 才 EV≥0（§3.3） |

**本場匯率預測（策略／Team Lead）：** 一週 **157.5**、一個月 **156.8**、三個月 **156.0**。  
→ 屬 **溫和偏日圓**，**不是**「未來一週有 ≥52.5% 機率走出 +6% 級 00706L 大勝」。

**粗算（說明「慢慢等」不適合）：**

- 若三個月匯價僅 157.8 → 156.0：方向對 00706L 理論約 **+2.3%（2×）**，再扣多日重置耗損／費用後，遠不如 §3.2 的贏局。  
- 槓桿 ETF **不適合**用「三個月日圓會升」當續抱理由（§3.5：持倉越久沙漏越快空）。

#### （3）全賣理由清單（不只「怕再跌」）

| # | 理由 | 說明 |
| :--: | :-- | :-- |
| 1 | **短線 Kelly EV 為負** | P(日圓升，持倉窗) ≈ **22–35%** ≪ **52.5%** → 續抱期望為負（見 §4.2） |
| 2 | **輸贏不對稱** | 輸 −7.12%／贏 +6.44%；勝率不夠時，「可能會升」仍被虧損腿吃掉 |
| 3 | **與 DCI 方向互斥** | DCI 偏路徑 A；00706L 偏日圓升。投機互斥 → 清 00706L、留 DCI |
| 4 | **已浮虧／近停損** | 停損 ≈ **19.31**；規則觸發為 **全倉**，非「中線看多就硬扛」 |
| 5 | **時間結構** | 預設 5–7 天；用三個月敘事續抱 = 策略禁止的用法 |

鐵律 1：**EV ≤ 0 禁止持有／進場**，不是「方向感覺對就可以留」。

#### （4）單就 00706L 續抱：Kelly／EV 計算（§3.2–3.3）

二元近似（一輪持倉）：

\[
\begin{align*}
r_{\mathrm{win}} &= +6.44\%,\quad r_{\mathrm{lose}} = -7.12\% \\
\mathrm{EV}(p) &= p\cdot 6.44\% + (1-p)\cdot(-7.12\%) \\
b &= 6.44/7.12 \approx 0.9045 \\
f^{*} &= \dfrac{p\,b - (1-p)}{b}
\end{align*}
\]

損益兩平：\(p^{*} = 52.5\%\)（EV≈0，\(f^{*}\approx 0\)）。  
公式依據：\(p_{\mathrm{be}} = |r_{\mathrm{lose}}|/(r_{\mathrm{win}}+|r_{\mathrm{lose}}|) = 7.12/(6.44+7.12) = 52.5\%\)。

| 主觀 P(日圓升，持倉窗) | **EV（一輪）** | **Kelly \(f^{*}\)** | **½ Kelly** | 含義 |
| :--: | :--: | :--: | :--: | :-- |
| **22%**（本場下沿） | **≈ −4.1%** | **≈ −64%** | 負 → **不持有** | 期望每輪約 −4% |
| **25%** | **≈ −3.7%** | **≈ −58%** | 負 | |
| **30%**（中位參考） | **≈ −3.1%** | **≈ −47%** | 負 | |
| **35%**（本場上沿） | **≈ −2.4%** | **≈ −37%** | 負 | 仍明顯為負 |
| 50% | ≈ −0.3% | ≈ −5% | 仍略負（耗損） | |
| **52.5%**（門檻） | **≈ 0** | **≈ 0** | 0 | EV 翻正臨界 |
| 60% | ≈ +1.0% | ≈ +16% | ≈ **+8%** 資金 | 開始正 EV |
| 70% | ≈ +2.4% | ≈ +37% | ≈ +18% 資金 | 積極正 EV |

**本場結論（單就 00706L 續抱）：**

- P ≈ **22–35%** → \(f^{*} \approx \mathbf{-37\% \sim -64\%}\)（**負**）  
- **½ Kelly 不適用正倉 → 最優張數 = 0**  
- **EV ≈ −2.4% ~ −4.1%／輪**

對 **8 張、成本約 158,480 TWD** 粗算（EV% × 成本，量級）：

| P | 約略期望損益（一輪） |
| :--: | :-- |
| 30% | 約 **−4,800 TWD** |
| 35% | 約 **−3,800 TWD** |
| 52.5% | 約 **0** |

（實際還依剩餘天數、是否貼停損、路徑連續性而變；**符號與「應持有 0」不變**。）

#### （5）若 Owner 主觀短線勝率更高？

- 須先**上修 P(持倉窗日圓升 1σ 級)**，不是改掉 Kelly 邏輯。  
- **P ≥ 52.5%** 才翻正；**P≈60%** 才有明顯正 \(f^{*}\)（約 +16%，½ Kelly 約 8% 資金）。  
- 本場各角合成 **未** 給到該短線勝率（JPY Bull 一週中樞 156.9 仍屬溫和）。  
- 若改為 **§3.7 換匯避險倉**，規則不同；本場為 **投機倉 + 與 DCI 並持** → 用投機 Kelly／互斥。
