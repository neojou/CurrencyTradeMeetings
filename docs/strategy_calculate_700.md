# strategy_calculate_700.md — 每筆 700 股最佳化計算過程

> 本文件記錄「為何每筆 700 股」是在當前策略目標與限制條件下，
> 最合適的下單單位，並完整呈現從交易成本、期望值、到股數反推的計算過程。

---

## 一、策略目標與限制條件

| 條件 | 設定值 |
|---|---|
| 月期望獲利目標 | ≥ 1,000 元（台幣） |
| 每月平均訊號次數 | ≈ 2.2 筆（來自 00706L 策略文件） |
| 優先考量 | **風險最低**（不以最大獲利為第一目標） |
| 停利（TP） | +6% |
| 停損（SL） | −3% |
| 交易標的 | 00706L（盤中零股） |
| 交易所 | 台灣證券交易所（TSE） |
| 券商 | 元大證券（盤中零股電子交易） |
| 示例股價 | 約 21 元（計算時以此為基準，實際以買入當日為準） |

## 二、交易成本計算

使用元大「盤中零股」電子交易費率：

| 費用項目 | 費率 | 說明 |
|---|---|---|
| 買進手續費（電子交易 6 折） | 0.0855% | 每筆最低 1 元 |
| 賣出手續費（電子交易 6 折） | 0.0855% | 每筆最低 1 元 |
| 賣出證券交易稅 | 0.3000% | 台股法定，無法免除 |
| **來回合計成本（cost）** | **≈ 0.471%** | 買＋賣＋稅 |

```

cost = 0.000855 (買) + 0.000855 (賣) + 0.003 (證交稅) = 0.00471 ≈ 0.471%

```

---

## 三、淨停利與淨停損（扣除成本後）

$\text{net\_win} = TP - \text{cost} = 6\% - 0.471\% = 5.529\%$

$\text{net\_loss} = SL + \text{cost} = 3\% + 0.471\% = 3.471\%$

> 這代表每贏一筆，你真正入袋的是投入金額的 **+5.529%**；
> 每輸一筆，你真正扣掉的是 **−3.471%**（含成本）。

---

## 四、損益兩平勝率（最低需求）

只要有效勝率高於此值，這套停利/停損組合在期望值上即為正：

$p_{BE} = \frac{\text{net\_loss}}{\text{net\_win} + \text{net\_loss}} = \frac{3.471\%}{5.529\% + 3.471\%} = \frac{3.471}{9.000} \approx 38.6\%$

> 解讀：哪怕你 10 筆只贏 4 筆（勝率 40%），這套 6/3 策略（含成本）在期望值上仍是正的。
> 若來回成本更高（例如整股），損益兩平勝率會略微上升。

---

## 五、單筆期望值（Expected Value per Trade）

以策略文件的歷史回測勝率 **p = 75%** 代入：

$EV = p \times \text{net\_win} - (1-p) \times \text{net\_loss}$

$EV = 0.75 \times 5.529\% - 0.25 \times 3.471\%$

$EV = 4.147\% - 0.868\% = \mathbf{3.279\%}$

> 解讀：平均每筆交易，對投入金額而言可期望獲得約 +3.28% 的淨報酬。
> 若勝率下滑（例如降至 65%），EV 也會同步下降，所需股數會相應增加。

### 勝率敏感度表

| 勝率 | 單筆 EV（%/筆） | 700 股月期望（2.2 筆） | 達月目標 1,000 元所需股數 |
|---:|---:|---:|---:|
| 55% | 0.316% | 約 102 元 | ≈ 6,840 股 |
| 60% | 0.843% | 約 272 元 | ≈ 2,565 股 |
| 65% | 1.370% | 約 441 元 | ≈ 1,580 股 |
| 70% | 1.897% | 約 611 元 | ≈ 1,141 股 |
| **75%** | **3.279%** | **約 1,057 元** | **≈ 660 股** |
| 80% | 2.951% | 約 951 元 | ≈ 733 股 |

> 注意：勝率 75% 時，660 股取整到 **700 股** 即可跨過月目標門檻。

## 六、反推最佳股數（目標 ≥ 1,000 元/月）

月期望報酬的公式為：

$E[\text{月獲利}] = EV \times N \times P_{entry} \times M$

- \(EV\) = 單筆期望值（以投入金額比例計）≈ 3.279%
- \(N\) = 每筆股數（待求）
- \(P_{entry}\) = 進場均價（示例 21 元）
- \(M\) = 每月平均訊號次數 ≈ 2.2 筆

設 \(E[\text{月獲利}] = 1{,}000\) 元，解 \(N\)：

$N = \frac{1{,}000}{EV \times P_{entry} \times M} = \frac{1{,}000}{3.279\% \times 21 \times 2.2} = \frac{1{,}000}{1.515} \approx 660 \text{ 股}$

**取整數向上 → 每筆 700 股**（確保在訊號數接近 2.2、勝率接近 75% 時，月期望能穩定跨過 1,000 元）。

## 七、700 股的每筆金額與風險量化

以示例股價 21 元計算：

| 項目 | 計算過程 | 結果 |
|---|---|---|
| 每筆名目金額 | 700 × 21 | 14,700 元 |
| 每筆預期獲利（停利觸發） | 14,700 × 5.529% | ≈ +813 元（淨） |
| 每筆停損金額（停損觸發） | 14,700 × 3.471% | ≈ −510 元（淨） |
| 月期望報酬（2.2 筆/月） | 14,700 × 3.279% × 2.2 | ≈ **+1,060 元/月** |
| 單筆來回手續費（買+賣） | 14,700 × 0.0855% × 2 | ≈ 25 元 |
| 單筆賣出證交稅 | 14,700 × 0.3% | ≈ 44 元 |
| **單筆總成本（買+賣+稅）** | 14,700 × 0.471% | ≈ **69 元** |

## 八、本金建議（與風控規則對齊）

根據 AGENTS.md 首批倉位建議壓在總資金 ≤ 15% 的原則：

$\text{建議最低本金} = \frac{14{,}700}{15\%} = 98{,}000 \approx \textbf{100,000 元}$

## 十、結論

$\boxed{每筆\ 700\ 股 = 在「月目標\ 1{,}000\ 元 + 勝率\ 75\% + 2.2\ 筆/月 + 成本\ 0.471\%」條件下的最小合適股數}$

**這不是數學全域最優解，而是在你的目標、成本、風控三重限制下反推出的最合適起點。**
若勝率或每月訊號數下降，需同步上調股數或放寬月目標，才能維持策略自洽。
