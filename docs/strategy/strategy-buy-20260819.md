## 2. 策略想法（比價日 8/26 兩條路）

報價慣例：USD/JPY **下跌 = 日圓升值**，**上漲 = 日圓貶值**。  
下文「日圓強過履約價」= USD/JPY **< 159.3**；「日圓弱過履約價」= USD/JPY **> 159.3**。

### 路徑 L：日圓升值、強過履約價（USD/JPY < 159.3）→ 轉成美元

- DCI 以 **159.3** 把本利換成美元。市價若已低於 159.3，等於用比市價更差的匯率換匯，這就是「被轉換的匯率損失」。
- 同一段日圓升值，00706L（日圓正 2 倍）上漲，用來補這段損失。
- 換到的 **12,579.41 USD 本身有用途**：可再做 **同一履約價 159.3 的反向美元 DCI**（USD→JPY）。若之後日圓回貶、USD/JPY 再站回 159.3 以上，可把美元換回日圓並再收一輪利息（即 `strategy.md` §2 的路徑 C）。若日圓繼續升，美元仍可留作現金／下一口。

### 路徑 H：日圓貶值、弱過履約價（USD/JPY > 159.3，例如 160.4）→ 留日圓

- DCI 不轉換，拿回本金 + 3,900 JPY 利息。
- 00706L 這張保險會賠。
- 假設 **USD/TWD 大致不變**，日圓對美元貶，對台幣也貶 → 同樣 40 萬台幣能換到**更多日圓**。這筆「一週後多換到的日圓」用來抵 00706L 的跌價。
- 40 萬 TWD 約等於目前 200 萬 JPY 本金（見 §5），所以這條路是在對沖「之後要用台幣補日圓部位」的換匯成本，不是另開一個無關的投機倉。

## 5. 一週後可能價位：推導

### 5.1 模型設定

以 **Black–Scholes／對數常態** 描述比價日收盤 \(S_T\)（USD/JPY）：

| 符號 | 取值 | 說明 |
| :-- | --: | :-- |
| \(S_0\) | 159.33 | DCI 成交即期 |
| \(K\) | 159.30 | 履約價 |
| \(T\) | 7/365 ≈ 0.01918 | 8/19 → 8/26 |
| \(\sigma\) | 8.0% | 見 §4 |
| \(r_{USD}-r_{JPY}\) | 3.75% − 1.00% = 2.75% | 一週遠期升水約 **+8.4 錢** |
| 遠期 \(F\) | \(S_0 e^{(r_d-r_f)T}\) ≈ **159.41** | 無事件時的中性錨 |

```
σ√T     = 0.011079
d2      = [ln(S0/K) + (rd−rf − σ²/2) T] / (σ√T) ≈ 0.059
N(d2)   = P(S_T ≥ K) ≈ 52.4%     ← 風險中性下「留日圓」
P(S_T < K)                   ≈ 47.6%     ← 「轉成美元」
```

K 幾乎 ATM，再加一週美元套息微幅正漂移，所以 **留日圓略多於半數**，但實務上就是擲硬幣。這不是主觀方向預測，是選擇權市場在 σ=8% 下的風險中性機率。

無條件 1σ／2σ 帶（中心用即期，方便對盤）：

| 帶 | USD/JPY | 意義 |
| :--: | :-- | :-- |
| 1σ（約 68%） | **157.56 – 161.10** | 一週最可能的活動區間 |
| 2σ（約 95%） | **155.80 – 162.86** | 超出此帶需要 CPI／干預／風險事件 |

再疊政策邊界：上檔 **160–162 干預敏感**，下檔干預後低點／布林下軌 **155.2–155.4**。有效的「會走到、且還站得住」的區間，比純 2σ 更窄，大約 **156.5–161.5**。

## 6. 兩條路的損益是否對得上

三角套算（假設 USD/TWD = 31.92 不變）：

```
現在 400,000 TWD → JPY = 400,000 / 31.92 × 159.33 ≈ 1,996,600 JPY
（約等於這筆 DCI 本金 200 萬日圓）

00706L 10 張價金 189,800 × 2 倍 ≈ 379,600 TWD
對 400,000 TWD 換匯名義的對沖比率 ≈ 95%
→ 設計上是「略少於全額」的換匯保險，不是 1:1 精準避險
```

### 6.1 路徑 L：轉美元（以條件中樞 157.9 為例）

```
市價換匯本應得到：2,003,900 / 157.9 ≈ 12,691 USD
實際按 159.3 只得到：12,579.41 USD
少拿：約 112 USD ≈ 17,600 JPY ≈ 3,560 TWD     ← DCI 匯率損失

00706L：USD/JPY −0.87% → ETF ≈ +1.75% ≈ +3,410 TWD
淨差額：約 −150 TWD（對沖比率 95% + 忽略耗損）
```

更深的 156.5：DCI 匯損約 7,180 TWD，ETF 約 +6,740 TWD，仍大致抵上，缺口約 400 TWD。  
這條路的「剩餘價值」不在這幾百元，而在 **手上的 1.26 萬美元** 可以開同 K 的反向 DCI。

### 6.2 路徑 H：留日圓 + 40 萬換日圓（以 160.4 為例）

```
DCI：2,003,900 JPY（多 3,900 利息）≈ +780 TWD

00706L：USD/JPY +0.67% → ETF ≈ −1.34% ≈ −2,550 TWD

40 萬 TWD 一週後可換：
  400,000 / 31.92 × 160.4 ≈ 2,010,000 JPY
  比今天多換：約 13,400 JPY ≈ +2,670 TWD

三項合計：+780 − 2,550 + 2,670 ≈ +900 TWD
```

若收到條件中樞 160.8：ETF 約 −3,500，多換日圓約 +3,660，加利息後仍大致打平。  
**前提全部成立時**，160–161 這一段「ETF 賠、換匯賺」可以對上；若 USD/TWD 同時大動（台幣跟日圓一起貶或一起升），這段抵銷會失準。

## 8. 主要風險（這次結構特有的）

1. **USD/TWD 不是真的不動。** 路徑 H 的「多換日圓補 ETF」完全靠這個假設。若台幣對美元升值、日圓卻對美元貶，40 萬換到的日圓增幅會縮小。
2. **00706L 是單日 2 倍期貨 ETF。** 公式 \(r_L \approx -2\Delta S/S\) 只對「一天」準；一週有路徑依賴與轉倉耗損，對沖會有幾個百分點的誤差。
3. **對沖比率 95%、且 ETF 有台股交易時間差。** 匯市週三比價、台股先收，8/26 當天 ETF 不一定走滿匯率。
4. **右尾被干預削、左尾被 CPI 加厚。** 模型給的 162 機率偏高、156 機率可能偏低；方向錯了不會爆，但條件中樞會從 157.9／160.8 各移 0.5–1 円。
5. **反向美元 DCI 不是自動必做。** 只有轉到美元、且判斷日圓會回到 159.3 以上時，第二輪 EV 才為正（見既有兩輪 DCI 討論）。
