### 直接結論：✅ 兩輪比單輪好，而且**在所有情境下都好**


***

### 核心機制解釋

**單輪**：觸發後只能乾等，完全暴露於日圓升值風險。

**兩輪**：觸發後多一個「救援機制」——第二輪把 41.35% 的觸發機率切成兩塊：

```
P(觸發) = 41.35%
  ├─ 路徑C（9.64%）：日圓先升後貶 → 換回JPY，賺兩輪利息 +6,743 JPY ✅
  └─ 路徑B（31.70%）：日圓持續升 → 留USD（與單輪相同，但USD本金多了11 USD利息）
```


***

### 三個關鍵數字

| 項目 | 說明 |
| :-- | :-- |
| **路徑C 貢獻** | P=9.64% × (+6,743 JPY) = **+650 JPY EV 貢獻** |
| **路徑B 改善** | 路徑B機率從 41.35% 降至 31.70%（因路徑C吸收了 9.64%），損失場景減少 |
| **兩輪總優勢** | 約 **+4,416 JPY**（S_end=152-155 平均），無論市場走哪個方向皆優 |

### 一句話總結

> **兩輪 DCI 的 EV 必然 ≥ 單輪 DCI**——因為第二輪是「免費的選擇權」：若日圓反彈，可以換回 JPY 多賺利息（路徑C）；若日圓繼續升，結果與單輪完全相同（路徑B）。在相同 K1、相同利率的前提下，**做兩輪嚴格優於做單輪**，這也正是 strategy.md §2 設計兩輪組合的數學依據。
