## 情境二：兩輪 DCI 組合 Kelly EV


***

### 計算架構說明

情境二是一個**條件式兩輪策略**，結構如下：

```
第一輪（JPY → USD）：
  路徑A（P=不觸發）：到期拿回 JPY + 利息 ✅ 結束

  路徑觸發 → 換得 USD，立刻啟動第二輪 ↓

第二輪（USD → JPY）：
  路徑C（P=觸發後不觸發）：USD/JPY 升回 ≥ K2，換回 JPY + 利息 ✅
  路徑B（P=觸發後再觸發）：日圓繼續升，持有 USD，以 S_end 估算損益 ⚠️
```


***

### 第二輪利率估算原理

> 第二輪條件：已觸發，USD/JPY 的**條件期望值** $S_0^{R2} = E[S \mid S < K_1]$

$$
S_0^{R2} = S_0 \cdot \frac{N(-d_1)}{N(-d_2)}
$$

第二輪緩衝 = $K_2 - S_0^{R2}$（方向相反，現在是希望日圓貶回），用插值估算對應利率：


| K1 | S₀_R2 | 第二輪緩衝 | 估算第二輪利率 |
| :--: | :--: | :--: | :--: |
| 157.0 | 155.376 | 1.624 円 | 3.55% |
| 156.5 | 155.031 | 1.469 円 | 4.22% |
| 156.0 | 154.668 | 1.332 円 | 4.90% |
| 155.5 | 154.287 | 1.213 円 | 5.58% |


***

### 與情境一的本質差異

```
情境一（單輪）：觸發 = 拿回 JPY 的「即時損失」
情境二（兩輪）：觸發 = 用 USD 再賭一輪，有機會賺回

路徑C（兩輪才有）= 觸發後日圓貶回 → 換回 JPY + 額外利息
這是「免費選擇權」——路徑C的報酬率達 +0.199%（K=155.5）
正因為有路徑C存在，EV 從 −0.131% 改善至 −0.049%
```


***

### 最終建議

**整體仍為負 EV，不建議進場。** 但與情境一相比有三個重要差異：


| 比較維度 | 情境一（單輪） | **情境二（兩輪）** |
| :-- | :--: | :--: |
| K=155.5 中性EV | −0.131% ❌ | −0.049% ❌（改善63%） |
| USD Bull × S_end=154 | −0.015% ❌ | **+0.024% ✅** |
| USD Bull × S_end=155 | +0.034% ✅ | **+0.055% ✅** |
| EV 翻正難度 | 需 P(不觸發) ≥ 93.9% | **需 P ≥ 83.8%**（低 10pp） |

> 📌 **結論**：
> - **中性假設下：兩輪仍為負 EV，不進場**（鐵律1）
> - **若 Owner 主觀 P(不觸發) ≥ 92%（USD Bull 強烈看漲，S_end=154）**，K=155.5 兩輪策略 EV 翻正 **+0.024%**，勉強值得考慮（½ Kelly）
> - **最敏感的假設是 S_end**：若相信觸發後日圓只升 2.4 円（S_end=155），風險中性本身 EV 就翻正
> - 等待 USD/JPY 回落至 **≤ 156** 後，兩輪策略的 EV 結構將大幅改善
