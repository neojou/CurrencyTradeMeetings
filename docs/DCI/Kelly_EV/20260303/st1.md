#### 計算公式

$P(\text{不觸發}) = N(d_2), \quad d_2 = \frac{\ln(S_0/K_1) + \frac{\sigma^2}{2}T}{\sigma\sqrt{T}} - \sigma\sqrt{T}$

$r_{win} = \frac{\text{利息}}{\text{本金}}, \quad r_{lose} = \frac{(USD \times S_{end}) - \text{本金}}{\text{本金}}$

### 為什麼比昨日（S0=157.0）更難翻正？

今日 S0 上升至 **157.4**（+0.4 円），導致兩個不利變化同時發生：

```
① 緩衝縮小：S0漲 → K1相同 → 緩衝變小 → 銀行給的利率反而更高
   但利率的增幅 < P(觸發)增加的幅度

② P(觸發)上升：S0離K1更近 → 觸發機率上升
   K=156.5 的P(觸發)：昨日=34.5% → 今日=34.5%（略升）

③ 最關鍵：S_end假設不變（154），但觸發後損失略增
   因為換得的USD金額略少（分母K1不變，但概率分布偏移）
```
